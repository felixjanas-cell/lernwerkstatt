🧠 Dein Lern-Workflow – 5 Methoden im Tool

  1. 🧑‍🏫 Feynman – jede Karte erst laut in eigenen Worten erklären, dann aufdecken.
  2. 🗺️ Mind Map – Excalidraw-Mindmaps: Galerie oben im Hub + in den Decks verlinkt (wo vorhanden).
  3. 🧠 Active Recall – die Selbsttests selbst: abrufen ohne Spicken.
  4. 🔁 Spaced Repetition – „Heute dran“ + Ampel (2 gute Tage = 🟢) + Wiederhol-Deck.
  5. 🍅 Pomodoro – Timer unten rechts (25/5 min) schützt deine Lernzeit.
Grundlage: Lernmethoden Übersicht · Empfohlener Ablauf: Feynman → Mind Map → Active Recall → Spaced Repetition, geschützt durch Pomodoro.
Fortschritt liegt lokal in diesem Browser (localStorage). Ampel-Regel: 🟢 = 2 Durchläufe ≥90% an verschiedenen Tagen (zählt voll) · 🔵 = 1× ≥90 %, bestätigen (zählt halb) · 🟡 = dran · 🔴 = neu / letzter <60%.
Simulator- & Wiederhol-Sessions zählen für Streak und Durchläufe (nicht für die Deck-Ampel). Ergebnis Claude melden → Vault-Lernampel (Lehrplan Meisterprüfung) wird gepflegt.
